# 开题 PPT 框架

开题模板将背景中的证据、一个可检验的问题、具体研究任务和后续工作连在一起。它提取参考材料的组织方式：绿色标题、横向递进背景、每页左右两项研究任务，以图和短说明表达。学校标识、个人履历导航和未公开项目材料没有作为通用模板资产发布。

## 页面与表达目的

| 页 | 内容 | 页面形式 |
|---|---|---|
| 1 | 问题、现状、对策依据、研究目标 | 四段背景证据链；目标标为拟议 |
| 2 | 一个可检验的研究问题 | 对象、比较关系、评价目标的整体关系 |
| 3–5 | 三项研究内容，每项拆成两个相关任务 | 每页左右任务，原生可编辑节点与箭头 |
| 6 | 拟开展工作与交付物 | 四阶段计划；不默认填完成日期 |
| 7 | 参考文献 | 原始出处、链接；核查细节留在备注与证据文件 |
| 可选 | 明确指定的已核查前期材料 | 每页最多两项，最多两页 |

## 最少输入与继续修改

```bash
node cli.mjs create "你的研究题目" --dir runs/my-proposal
```

默认生成离线结构草稿，未调用文献或付费模型接口。临床研究、公开证据评价与通用题目采用相应的规则框架。题目会保留在项目文件、内容 JSON 和 PPT 备注中。未核查背景有明确提示；研究任务是拟议方案。可直接编辑 JSON 后重建 PPT。

```bash
node cli.mjs build runs/my-proposal/output/spec.images.json
```

进一步提供项目条件时使用 `examples/brief.template.json`：人群、参照关系、可用信息、时点、评价目标、已完成工作和未知条件。不要填患者资料或模型密钥。修改过的题目或模板请放入新的项目目录。

```bash
node cli.mjs create "你的研究题目" \
  --brief examples/brief.template.json \
  --query "English PubMed expression" \
  --dir runs/with-literature
```

有自己的模型密钥时，可用 `--provider openai` 根据题目和条件生成更具体的任务。默认 `--mode native` 保持节点和箭头可编辑；`--mode openai` 将选定设计图改为可独立替换的位图，其内部形状无法逐个编辑。模型文字与图像接口的完整付费路径尚未用真实账户验收，测试使用可控的模拟响应。

离线项目后续接入检索，请先运行 `research project.json`，完成主张核查后再显式 `plan project.json`，最后 `run project.json`。`run` 优先保留已有证据和手改内容，不会自动清空它们或重新规划。

## 证据与图如何对应

来源的 `claims[]` 可以通过 `backgroundRole` 指定背景位置：`problem`、`status`、`approach`、`goal`。没有指定位置的已核查主张按顺序选用；研究人员仍须确认是否支持相应段落。真实数字、单位、比较组和统计量说明都必须来自核查过的原文。

前三栏的实证主张需要完整核查记录与真实图数据或许可原图。第四栏通常是题目对应的研究目标，使用明确标为拟议的原生图；不需要把目标伪装成已发表结果。`--final` 允许这种已标识目标，同时阻止未核查的背景事实。通过这一检查只表示记录齐备，不代表科学结论或投稿已获批准。

图数据的均值/计数身份与脚注跟随核查主张保存，不能在排版中偷偷更改解释。背景实证图不会由图像模型生成。未知数据、缺失样本量、未定义的终点继续保留为未知。

## 可选前期基础

在 brief 中列出已核查材料对应的主张 ID：

```json
{"preliminaryClaimIds": ["your-reviewed-figure-claim"]}
```

该主张必须存在于提供的证据文件，书目信息与科学主张均已核查，并有真实图数据或可复用原图。未知 ID、未核查主张、生成示意或许可不明的原图会明确报错。程序不会因为 `completedWork` 中写了一句话，就编造一页前期实验结果。公开文献基础与项目自有结果要按来源说明其身份。

## 离线示例

```bash
npm run demo:proposal
```

`examples/proposal/` 包含示例项目、证据与内容 JSON。示例使用历史脓毒症疾病负担、PCT诊断综述以及单中心 PD-1观察队列的数据；PCT的原比较是非感染性SIRS，PD-1图比较的是28天结局组。二者不能被当成同一终点的模型增益证明。免疫候选信息的增量价值作为待检验问题。

示例研究内容与计划全部为拟议。没有病例记录、实际项目样本量、检测覆盖率或未公开结果。中文字体可通过 `project.design.fontFace` 或 `spec.theme.fontFace` 设置为本机已安装字体；示例使用 Arial Unicode MS，其他电脑可能替换字体，应重新查看版式。
