# 植物来源天然产物抗流感：完整范例

本范例按植物来源材料的研究问题组织：粗提物候选价值与效应—毒性边界、活性成分关联、直接作用与宿主反应解释、候选开发与转化。保留“植物 X”“粗提物 X”“NP”标记，没有推断未提供的植物或化合物身份。

```bash
npm ci
npm run demo
```

输出 `build/proposal/research-slides.pptx`，共八页。正文、重绘数据、区间端点与流程可编辑；真实论文原图和设计插图可独立移动、增删或替换。

## 真正用到的来源

| 位置 | 来源 | 图与结论的范围 |
|---|---|---|
| 背景：问题 | Li et al., Lancet Public Health,2019；DOI10.1016/S2468-2667(19)30163-X | 中国历史流感相关超额呼吸死亡率；点和95%CI都来自Table1，未推算中点 |
| 背景：现状 | Hayden et al., NEJM,2018；DOI10.1056/NEJMoa1716197 | 巴洛沙韦与安慰剂的症状缓解中位时间；非复杂流感门诊人群 |
| 背景：候选依据 | Geng et al., Front Pharmacol,2020；DOI10.3389/fphar.2020.01298 | 真实Figure1D宿主反应结果，CCBY4.0；原轴从90%起，保留坐标和图例 |
| 独立研究依据 | Hour et al.,2013；DOI10.1155/2013/750803 | 已报告的体外选择性比值2.5与2.3；不作临床治疗窗解释 |

现药的临床结局不是天然产物临床疗效证明。黄芩素、黄芩苷是外部文献实例，不直接赋予植物 X 或 NP。原稿中的 PMID38070793 对应肺癌天然多糖综述，没有作为抗流感证据引用。已撤稿的 Li/Wang2019文章也未采用。全部研究任务与计划为拟议，图中没有新增项目阳性结果。

## 文件

- `project.json`：题目及项目身份约束。
- `evidence.json`：主张、数字、来源位置、适用范围与核查记录。
- `spec.json`：与题目对应的八页内容及版式。
- `assets/manifest.json`：原图出处、许可和三幅原创设计图的身份。

原始项目材料未打包进范例。所有实证图来自可核查的公开来源；设计图不承载数据或操作条件。第三方图像遵守自己的许可，代码MIT许可不覆盖原文权利。
